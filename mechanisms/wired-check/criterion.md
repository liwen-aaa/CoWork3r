## 判据：台账声称的检查命令必须存在且已接线

台账「落点」列里写 `npm run <x>` 的每一条：

- `package.json` 的 scripts 里必须真有 `<x>`；
- 且 `<x>` 必须挂在**会自动跑的钩子**上（`test` / `pre*` / `post*` 串起来的那些）。

存在但没接线 = **没人调用的检查器，比不存在更坏** —— 因为台账声称有机制，
于是你以为它在跑（D-02 的精确形态）。

## 怎么改

- script 不存在：写它，或把台账那条的落点改回「规约」（承认它会被跳过，这是诚实的）。
- script 存在但没接线：串进 `package.json` 的 `pretest`（或该生态的每轮钩子）。

## 来源

台账里写着 `npm run check:disciplines`，而那个 script 当时根本不存在 ——
声称有机制的纪律，活在「文档说有」的状态里过一阵，没人发现。
