# 纪律（disciplines）

> 本文件是**判据集合**，不是说明文档。每条给出：判据（怎么判断违反了）＋ 落点（在哪被强制）。
> 落点为「规约」= 只写在文本里，**接受它会被跳过**（D-02）；落点为路径 / 命令 = 有机制。
>
> **只增不改**：旧条目正文不动，修订另起一条并标注取代关系。条目按编号严格递增排列 ——
> 乱序会掩盖删除。机制：`node scripts/mech.mjs run append-only-ledger`。
>
> ## 这张表为什么几乎是空的
>
> 下面两条是 day 0 唯一有资格进表的 —— 它们装了工作流就有落点，不需要本项目先出事故。
> **第三条等第一次真实事故。** 一条经验进这张表的许可是：它在本项目能写出「会红的真实输入」，
> 或者已经有机制在跑它。写不出就是仪式 —— 拷一份四十条判据过来，每条落点都是「规约」，
> 那是一份很有说服力而全部会被跳过的文档。
>
> 候选池（上游仓库的完整台账）：`node scripts/mech.mjs list` 看有机制的那些；
> 其余判据在上游 `docs/disciplines.md`，撞上对应形状时再取，**取的时候连机制一起取**。
